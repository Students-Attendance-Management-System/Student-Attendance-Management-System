# Student Attendance Management System (SAMS)

## Project Overview
The Student Attendance Management System (SAMS) is a software engineering mini-project designed to manage student attendance, course enrollment, attendance reports, and related user roles.

## Objectives
- Provide secure login and role-based access for Admins, Teachers, and Students.
- Manage courses, sections, schedules, and student enrollment.
- Record and correct attendance.
- Generate attendance percentages and defaulter reports.
- Support low-attendance notifications and student leave requests.

## Main Modules
- Authentication and Role Management
- Course and Enrollment Management
- Attendance Management
- Reports and Analytics
- Notifications and Leave Management
- Security and Testing
